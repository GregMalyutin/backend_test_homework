# Фитнес-клуб: лестница или день ног

Консольная программа с готовыми планами тренировок для фитнес-клуба.

## Что внутри

1. **Тренажёр «лестница»** — кардио-интервалы на StairMaster / степпере (~25 мин)
2. **День ног** — силовой комплекс: приседания, жим ногами, румынская тяга, выпады и изоляция (~55 мин)

Также есть краткое сравнение, когда что выбирать.

## Запуск

```bash
python program.py
```

При запуске выберите:

- `1` или `лестница` — план на лестничном тренажёре
- `2` или `ноги` — силовой день ног
- `3` или `оба` — оба плана сразу

## Использование как модуля

```python
import program

print(program.recommend("лестница"))
print(program.recommend("ноги"))
print(program.compare())
```
